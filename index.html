Frequently asked questions

Is it safe to use these PDF tools for private documents?

Yes. The tools process files on your own device with JavaScript, and nothing is sent to a server.

Do I need to sign up or install anything?

No. The tools are free and work in any modern browser on a computer or phone.

Can I remove a password from any PDF?

Only if you know the password. The unlock tool removes a password you already have and does not crack unknown passwords.

Why is my compressed PDF text not selectable?

The compressor re-renders pages as images to reduce size, so keep your original file for copying text.
