How to edit a PDF online for free

PDFs are built to keep their layout, which is why they are hard to change. This PDF editor lets you make the common changes directly in your browser: add new text anywhere on a page, place an image such as a logo or a scanned signature, and white-out anything you want to hide or replace. You can drag every item to the right spot, resize images and change the size, colour and weight of text.

Because the editor runs on your own device, the PDF is never uploaded. That makes it safe for forms, resumes, invoices, certificates and other documents with personal details. It works with any PDF that is not password protected. If your file is locked, remove the password first with the Unlock PDF tool, edit it, and then download the new copy.

How to use it

  1. Drop your PDF onto the upload area, or click to choose a file.
  2. Choose Add Text, Add Image or White-out from the toolbar, then click on the page to place it.
  3. Type your text, then drag it into position and adjust the size, colour or bold setting.
  4. To replace existing text, white-out the old words first and add the new text on top.
  5. Click Download Edited PDF to save the finished file.

Tips

  • Click an item to select it, then press Delete to remove it.
  • Zoom in before placing small text so that it lines up with the original lines.
  • A PDF made from a scan is a picture of a page, so you can cover and add text, but the original words are not editable text.
  • Keep the original file, and save your edited version under a new name.

Frequently asked questions

Can I edit the existing text in a PDF?

You can replace it. Use White-out to cover the old words and then add new text over the top. Changing the original text object in place is not possible in a browser-based editor.

Does the editor add a watermark or require signup?

No signup is needed and the file is processed on your device.

Can I edit a password-protected PDF?

Not directly. Use the Unlock PDF tool first if you know the password, then edit the unlocked copy.

Is my PDF uploaded to a server?

No. All editing happens in your browser, and the file never leaves your device.
