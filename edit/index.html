✏️ Edit PDF

Add text, images, or white-out any content on a PDF. Click a tool, click on the page to place it, then download the edited PDF.

📄
Drop PDF here or click to select
Works with any PDF — no password required (use Unlock tool first if needed)
🔒 All editing happens in your browser. Your PDF is never uploaded to any server.

How to use

  • Add Text — select the tool, click anywhere on the page, start typing. Drag to reposition.
  • White-out — select the tool, click and drag to draw a white rectangle over any content you want to hide or replace.
  • Add Image — select the tool, click on the page to open the image picker, place the image, drag/resize as needed.
  • To replace text: first white-out the old text, then add new text on top.
  • Click any element to select it, then press Delete or click ✕ to remove.
