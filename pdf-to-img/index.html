Tips

  • PNG format keeps text crisp — better for documents with text
  • JPG is smaller — better for photo-heavy PDFs
  • High quality (2×) gives sharper images and is good for most use cases
  • Each page becomes a separate image file

When to Convert PDF to Image

Converting PDF pages to images is useful when you need to embed a PDF page in a presentation, share a document preview on social media, or use PDF content as a thumbnail. PDFCraft uses PDF.js — the same engine Firefox uses — to render each page to a canvas and export it as JPG or PNG.
