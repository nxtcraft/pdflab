How to number the pages of a PDF

Page numbers make long documents easier to read, cite and print. This tool stamps numbers on every page of a PDF. You choose the position (top or bottom, left, centre or right), the format (1, Page 1, 1/10 or Page 1 of 10), the font size, the colour and the starting number.

You can skip the first page, which is useful when the cover should not be numbered. The processing is done in your browser and the file is not uploaded.

How to use it

  1. Drop your PDF onto the upload area.
  2. Choose the position and the number format.
  3. Set the font size, colour and start number, and tick Skip first page if needed.
  4. Press Add Page Numbers and download.

Tips

  • Bottom center in the Page 1 of 10 format is the most common style for reports.
  • If your document starts with a cover and contents page, set the start number so the first main page is 1.
  • Merge your files before numbering so the numbers run continuously.
  • Use Reorder Pages first if the pages are not in their final order.

More questions and answers

Can I start numbering from a number other than 1?

Yes. Change the start number.

Can I skip the cover page?

Yes. Tick Skip first page.

Which formats are available?

1 2 3, Page 1, 1/10 and Page 1 of 10.

No.
