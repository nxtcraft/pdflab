How to combine PDF files into one

Applications for jobs, visas, loans and universities often ask for all documents in a single PDF. This tool joins up to 20 PDF files into one document in the order you choose. It runs in your browser, so your certificates, bank statements and ID documents are not uploaded to anyone's server.

You can add files in the order you want them, then drag them into a new order before merging. The merged PDF keeps the pages exactly as they were, one document after another.

How to use it

  1. Select all the PDFs you want to combine, or add more files one by one.
  2. Drag the file list into the correct order.
  3. Press Merge PDF.
  4. Download the combined file.

Tips

  • Name your files 01, 02, 03 so they sort correctly when you select them.
  • If you need more than 20 files, merge them in two rounds and then merge the two results.
  • After merging, use Compress PDF if the file is too large for an upload limit.
  • Use Reorder Pages or Delete Pages afterwards to fine-tune the final document.
