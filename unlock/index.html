How to remove a password from a PDF

This PDF password remover creates a copy of your file that opens without a password. You enter the current password once, the tool decrypts the file inside your browser, and you download an unlocked version. It supports the common PDF encryption types: RC4, AES-128 and AES-256.

People usually need this for documents they open often: an Aadhaar PDF, a bank or credit-card statement, a payslip, Form 16 or an ITR acknowledgement. Removing the password makes the file easier to attach to a form, merge with other documents or print, without typing the password every time.

How to use it

  1. Drop the password-protected PDF onto the upload area.
  2. Type the current password. For an Aadhaar PDF it is the first four letters of your name in capitals followed by your birth year, for example PRIY1990.
  3. Press Unlock PDF.
  4. Download the unlocked copy, and delete it when you no longer need it.

Tips

  • You must know the existing password. This tool cannot crack or guess an unknown password.
  • Use it only on files you own or have the right to unlock.
  • If you forgot a password for a bank or tax document, ask the issuer to send the file again. The password rule is usually written in the email or SMS that carried it.
  • Once the password is gone, anyone who gets the file can open it, so store the unlocked copy safely.
