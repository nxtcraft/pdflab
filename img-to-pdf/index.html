Convert Images to PDF — Common Uses

Converting images to PDF is one of the most common document tasks. Use cases include: sending scanned documents by email, combining photos into a single sharable file, converting WhatsApp-shared screenshots to a PDF report, and creating a photo portfolio PDF.

Yes — select multiple images at once and they'll be combined into a single PDF, one image per page, in the order you select them.
