How to Remove a Password from a PDF

A password-protected PDF is annoying when you open the same file often or need to attach it to a form. This guide shows how to remove the password from a PDF you own, for free, without installing software and without sending the file to a server.

Open the PDF password remover →

Before you start: what this can and cannot do

You can remove a password only if you already know it. Removing the password means opening the file with the right password and saving a copy that no longer asks for one. There is no honest way to open a protected file without the password, and no tool can guess a strong password in a reasonable time.

Use this only on documents that belong to you or that you have permission to unlock.

Step by step

  1. Open the Remove PDF Password tool.
  2. Drop your protected PDF onto the upload area.
  3. Type the password and press Unlock PDF.
  4. Download the unlocked copy and open it to check that no password is asked.
  5. Delete the unlocked copy when you no longer need it.

Common passwords for Indian documents

Aadhaar PDF: UIDAI uses the first four letters of your name in capital letters followed by your year of birth, for example PRIY1990.

Bank statements, credit-card bills, payslips and tax documents: each issuer sets its own rule. It is usually written in the email or SMS that came with the file, and some issuers use a date of birth, part of a mobile number or a PAN-based pattern. Check the message the file arrived with.

What if you forgot the password?

Ask the issuer to send the document again, and read the password instructions in that message. Employers and banks can usually regenerate a payslip or statement. If you set the password yourself and lost it, an old backup copy of the file is your best option.

Keeping your documents safe

Once a PDF has no password, anyone who gets the file can read it, so keep it in a folder you control and do not leave unlocked copies in shared drives. This tool works inside your browser, so the file and the password are not sent anywhere.

Frequently asked questions

Can I remove a PDF password online for free?

Yes, if you know the password. Open the PDF in the unlock tool, enter the password once and download an unlocked copy.

Is it safe to unlock a PDF in the browser?

It is safer than uploading, because the file is processed on your own device.

Does unlocking change the content?

The pages are kept, and the new copy opens without a password.
