How to Merge PDF Files into One Document

Job, visa, loan and university applications usually ask for a single PDF. This guide explains how to combine several PDFs into one in the right order and tidy up the result.

Open the PDF merger →

Step by step

  1. Open the Merge PDF tool.
  2. Select all the PDF files, or add them one by one.
  3. Drag the list into the order you want.
  4. Press Merge PDF and download the combined file.

Prepare your files first

Name files 01, 02, 03 so they sort correctly. Rotate any sideways pages and delete pages you do not need before you merge.

More than 20 files?

One merge accepts up to 20 files. Merge them in groups, then merge the results.

Finish the document

Add page numbers so that readers can refer to pages. Reorder pages if something is out of place. If the final file is too large for an upload, use the compressor.

Frequently asked questions

How many PDFs can I merge?

Up to 20 in one go.

Does merging change the pages?

No. The pages are combined in the order shown.

Is it free?

Yes. The tool is free and runs in your browser.
