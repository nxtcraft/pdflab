How to Edit a PDF Online for Free

You do not need paid software to fill in a form, fix a typo or add a logo to a PDF. This guide explains what you can change in a browser-based PDF editor and how to do each task step by step.

Open the free PDF editor →

What you can change

Add new text anywhere on a page, in a size, colour and weight you choose. Place an image such as a logo, a stamp or a scanned signature. White-out any content to hide it. Every item can be dragged to the right place and removed again with the Delete key.

Fill in a form or add text

  1. Open the Edit PDF tool and drop your file onto it.
  2. Choose Add Text and click where the text should go.
  3. Type your text, then drag it into position.
  4. Adjust the size so it fits the field, and download the edited PDF.

Replace existing text

A PDF stores text as drawn shapes rather than a flowing paragraph, so you cannot simply retype a word. The reliable method is to white-out the old text with a white rectangle and then add the new text on top. Match the size and weight so the change is not noticeable.

Add a logo or signature image

Choose Add Image, pick the file and click on the page. Drag the image into place and resize it with the handle in the corner.

Limits to know about

A scanned PDF is a picture, so you can cover areas and add text, but you cannot edit the original words. Files protected with a password must be unlocked first. For large rewrites, converting the PDF to Word may be easier, but expect some formatting changes.

Frequently asked questions

How do I edit a PDF for free?

Open a browser-based PDF editor, add text, images or white-out, and download the new file.

Can I edit a scanned PDF?

You can add text and cover areas, but the scanned text itself is a picture.

Is editing in the browser private?

Yes, when the tool runs locally. The file is not uploaded.
